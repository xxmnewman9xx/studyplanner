# Build 42 Coach Voice Audit

Date: 2026-06-05

Scope: copy, tone, and coach language only. No features, no architecture changes, no version changes.

## Voice Rule

The model can stay smart. The copy should stay short.

Target: calm, direct, premium, Apple-native.

## Semester Health

Old copy:

- "Preparedness is the limiting factor: Upcoming exams are mapped; add notes or complete review blocks to raise preparedness."
- "Workload is realistic if the current plan holds."
- "The plan is being followed consistently."

New copy:

- "Add notes or review."
- "On pace."
- "On rhythm."

Reasoning:

The score and dimensions already carry the data. The sentence should name the state, not explain the model.

## Health Dimensions

Old copy:

- "3 forecasts need current grades for precision."
- "Consistency starts with the first completed study block."
- "Exam prep is light for 1 upcoming exam."

New copy:

- "Add grades."
- "Start one block."
- "Exam prep is light."

Reasoning:

Each dimension now reads like a coach prompt instead of a dashboard explanation.

## What Matters Now / Next Action

Old copy:

- "BIO 101 exam mode. Midterm exam is in 13 days. One 30 minute review protects the B- forecast."
- "CS 214: Problem Set 3 is yesterday. A 45 minute first pass repairs the biggest risk."

New copy:

- "BIO 101 exam mode. Review Midterm exam. 13 days."
- "CS 214: recover Problem Set 3."

Reasoning:

The user needs the next move. The rationale can live below the surface, not inside the headline.

## Class Pulse

Old copy:

- "Estimated from completion, deadlines, notes, and study behavior."
- "Add your current grade for a tighter forecast."
- "BIO 101 forecast B-"

New copy:

- "Estimated."
- "Add grade."
- "BIO 101 B-"

Reasoning:

Class Pulse should answer: grade, direction, action. Nothing more.

## Grade Forecast

Old copy:

- "Projected B+ if current pace holds."
- "BIO is trending down because the exam is close and prep is light."
- "Add your current grade to unlock a tighter forecast."

New copy:

- "Stable."
- "Prep is light."
- "Add grade."

Reasoning:

Forecast labels already show the academic state. Copy should show condition and action.

## Pressure Forecast

Old copy:

- "1 overloaded day"
- "Move one review block before Wednesday."
- "No immediate deadline is blocking the day."

New copy:

- "Heavy week"
- "Lighten Wednesday."
- "Clear day."

Reasoning:

Pressure language should behave like weather: short, readable, status-driven.

## Plan Autopilot

Old copy:

- "Study blocks are generated from due dates, workload estimates, exam proximity, scanned notes, and unfinished work."
- "Moved Finance review to Tue to avoid overload."
- "Large assignments were split into smaller focus blocks."

New copy:

- "Plan is balanced."
- "Finance review moved to Tue."
- "Large work split."

Reasoning:

The user does not need implementation details on the Plan screen.

## Study Sessions

Old copy:

- "Completing this block strengthens Preparedness and supports BIO 101, currently projected B-. This is not just a checkbox; it reduces semester risk."
- "Work only on this item, then answer the active-recall prompt below."
- "Without looking, explain the key idea, formula, or next step for this task."

New copy:

- "BIO 101 preparedness. B- forecast."
- "One item. Then recall."
- "Explain it without looking."

Reasoning:

Study Session should create focus, not read like a product explanation.

## Feedback Events

Old copy:

- "Good save. Preparedness 68 -> 79."
- "Imported 12 reviewed items. The semester plan updated."

New copy:

- "Preparedness +7."
- "12 items imported."

Reasoning:

Feedback should feel like movement: short outcome, clear gain.

## Notifications

Old copy:

- "BIO 101: one focused block protects the week."
- "One active-recall pass tonight protects your forecast."
- "45m now keeps the semester moving."

New copy:

- "BIO 101: one block keeps pace."
- "One recall pass tonight."
- "45m. Stay ahead."

Reasoning:

Notifications are smallest-surface copy. They must be fast and calm.

## Widgets

Old copy:

- "Next Action"
- "Semester Health"
- "Grade forecast"
- "Use the space for review."

New copy:

- "Next"
- "Health"
- "Forecast"
- "Stay ahead."

Reasoning:

Widgets should be the shortest copy in the app.

## Notes Intelligence

Old copy:

- "Notes feed exam readiness."
- "Note intelligence"
- "AI Summary"
- "This note improves preparedness once it is reviewed and turned into recall work."

New copy:

- "Notes build readiness."
- "Signals"
- "Summary"
- "Readiness up."

Reasoning:

The product should not keep naming intelligence. It should simply show useful signals.
