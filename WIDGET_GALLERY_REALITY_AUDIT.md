# Widget Gallery Reality Audit

Date: 2026-06-02

## Summary

StudyPlanner has four real native WidgetKit outputs today. The new Widgets tab presents six student-facing gallery choices, but those choices are product labels over the existing real snapshot pipeline, not six separate WidgetKit extensions.

## Which Widget Outputs Are Real?

Real shipped WidgetKit/Home Screen outputs:

- Today: `studyplanner.today`, `StudyPlannerTodayWidget`
- Upcoming: `studyplanner.upcoming`, `StudyPlannerUpcomingWidget`
- Week: `studyplanner.week`, `StudyPlannerWeekWidget`
- Class Progress: `studyplanner.classProgress`, `StudyPlannerClassProgressWidget`

Source: `src/widgets/widgetPresets.ts`, `src/widgets/StudyPlannerWidgets.tsx`, `docs/WIDGETKIT_DATA.md`.

## Which Previews Are Fake Or Static?

- The in-app `WidgetPreviewCard` is a React Native preview, not WidgetKit. It can be real when fed by `buildStudyPlannerWidgetSnapshots`, which the new live preview does.
- Gallery labels such as Exam Countdown, Next Class, Focus Window, Semester Pulse, and Future Risk are not separate native WidgetKit kinds. They map onto the four real native snapshot kinds.
- Old Widget Studio controls for size/style/surface were UI customization concepts, not guaranteed separate WidgetKit output.
- Watch/lock setup concepts still exist in the broader model for legacy/internal paths, but the Widgets tab no longer renders Watch preview UI, lock controls, or fake setup cards.

## Which Settings Affect Actual Widget Snapshots?

Actual snapshot inputs:

- `semester`
- `courses`
- `assignments`
- `parsedImports`
- `focusSessions`
- `settings`
- `widgetPresets`
- `demoMode`
- `locale`
- `translate`

Persisted native customization that affects snapshots:

- `widgetPresets`: native kind, data mode, layout, theme/background/palette, size, class focus id, icon, timestamps.
- `settings.customization.homeWidgetPack`: can override snapshot accent/background/style metadata through `nativeSnapshotStyleOverride`.
- `settings.syncEnabled`: when false, iOS gets private `sync_disabled` snapshots.
- `settings.privacyMode`: hides planner specifics in snapshot copy/colors.

Settings that should not be treated as real WidgetKit customization:

- Watch preview style.
- Lock/watch widget packs.
- Pure style picker UI that does not correspond to saved snapshot fields.

## Where Class Colors Are Stored

Class colors are stored on `Course.color` in `src/models.ts`.

The Widgets tab now changes `Course.color` through `onUpdateCourse(course.id, { color })`. That same field is consumed by:

- Class cards.
- Assignment/exam cards.
- Widget snapshot items as `courseColor`.
- The live widget preview accent via `previewSnapshot.items[0].courseColor` or selected course color fallback.

## Where Widget Snapshots Are Generated

Snapshots are generated by `buildStudyPlannerWidgetSnapshots` in `src/services/widgetSnapshot.ts`.

They are synced by `syncStudyPlannerWidgets`, which calls the Expo widget modules in `src/widgets/StudyPlannerWidgets.tsx`.

## Does WidgetKit Read Saved Customization Directly?

No. WidgetKit reads App Group timeline snapshot data written by `updateSnapshot`.

Saved app customization and widget presets matter only after the app converts them into snapshot fields and writes those snapshots. WidgetKit does not read `PlannerData`, `settings.customization`, or `widgetPresets` directly.

## Implementation Decision

The replacement Widgets tab is a Widget Gallery, not a Widget Studio:

- Header: “Widgets / Your school, on your Home Screen.”
- One recommended card.
- One large real snapshot-backed live preview.
- Six gallery choices.
- Compact class color editing.
- Simple add instructions.

No parser, IAP, storage, backend, WidgetKit snapshot generation, or app name changes were made.
