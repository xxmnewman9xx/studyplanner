## Patterns Applied

- Ask only profile questions that change the immediate experience.
- Use name personalization early.
- Show an artifact/proof moment before paywall when possible.
- Make payment feel like applying/unlocking a plan the user already started.
- Keep setup fast and reduce abstract configuration.
- Keep restore, terms, and privacy visible.
