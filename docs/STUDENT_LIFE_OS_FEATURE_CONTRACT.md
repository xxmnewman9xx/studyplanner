# Student Life OS Feature Contract

Date: 2026-05-31

## Product Rule

StudyPlanner is not a planner with many screens. It is a Student Life OS.

Every feature must prove one of four outcomes:

- Organize the semester from messy school input.
- Tell the student what matters now.
- Prevent future overload.
- Make the system adapt to the student's life.

Allowed statuses:

- Hero: primary product value.
- Supporting: visible only when it strengthens a hero.
- Hidden: utility, detail, or system state.
- Deleted: no clear user outcome.

Anything scoring below 8.5/10 is redesigned, hidden, or deleted before UI work.

## Hero Feature List

- Syllabus Import
- AI Review Inbox
- Student Life Feed
- Forecast
- Life Studio
- Widget Studio as a supporting hero
- Watch as a supporting hero

## Deletion List

Delete as primary concepts:

- More Hub
- Generic Notes / Agenda Notes as standalone destination
- Demo Planner as visible product surface
- Cosmetic theme gallery
- Widget cosmetic variants
- Widget sync/readiness diagnostics as a user surface
- Recent Imports as standalone section
- Standalone Course Hub tab
- Standalone Grades tab
- Standalone Focus tab

Hide in secondary settings or context:

- Locale controls
- Privacy mode
- Calendar sync
- App theme/accent controls
- Assignment detail
- Course data editing
- Import history

## Redesign Required

Below 8.5 features must be redesigned before UI implementation:

- Student Life Feed: stronger outcome hierarchy, less dashboard.
- Quick Capture: instant capture, not form entry.
- Forecast/Calendar: predictive Forecast, not calendar clone.
- Survival Plan: rename and merge into next-best-action Forecast.
- Classes/Course Hub: hide as data/detail.
- Assignment Detail: reduce chrome.
- Grades: become Grade Impact.
- Focus Timer: Life OS-driven protected work.
- Notes: delete or attach to tasks/classes only.
- Widget Studio: generated gallery, not controls.
- Lock Screen/Watch/StandBy: distinct jobs, no duplicates.
- Theme/Locale/Privacy: hide utility controls.
- Paywall: sell adaptation outcomes.
- Recent Imports/Parser Status: fold into Review Inbox.

## Reviewer Directives

Product Strategist:

- Four surfaces only: Feed, Scan, Forecast, Life.
- Reframe utilities as outcomes.
- Merge Survival Plan, Focus Sessions, and Reminders into adaptive action.
- Delete More Hub, generic notes, demo planner, theme knobs.

Apple Product Designer:

- Life must feel like "My Operating System."
- Remove settings, diagnostics, and generic controls from primary UI.
- Every card answers: what should I do, why now, what changes if I act?

UX Researcher:

- First use must prove value in under 60 seconds.
- Trust needs one visible system: Review Inbox plus confidence.
- Reduce cognitive load by hiding operations until needed.

Frontend Craft Reviewer:

- Kill More as an IA object.
- Hide parser/sync/locale/privacy utilities unless actionable.
- Any feature not visibly changed by Life OS should be removed or redesigned.

Widget Reviewer:

- Widget Studio starts from Life OS, not widget types.
- No generic widgets or cosmetic variants.
- Home Screen: daily view. Lock Screen: urgent glance. Watch: immediate action. StandBy: ambient forecast.

Watch Reviewer:

- Watch shows one signal, one action, one escalation.
- No stats or generic calendar mirrors.
- Wrist value must be understandable in 3 seconds.

Monetization Reviewer:

- Plus sells adaptation, not features.
- Free path: scan once, review, basic Feed.
- Paid path: Life OS powers Forecast, reminders, widgets, Watch.
