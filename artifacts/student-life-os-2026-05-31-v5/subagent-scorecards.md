# Student Life OS Scorecards

Screens reviewed were real iPhone simulator captures past onboarding/paywall, not locked demo/paywall states. Reviewers used the Life Studio North Star image as the visual reference.

## Apple Product Designer

- Contact sheet: v2
- Overall: 6.8/10
- Category scores: visual taste 7, Apple-native feel 6, hierarchy 7, simplicity 6, delight 8
- Main issues: repeated Life OS shell, dense first viewports, heavy bordered card language, less premium dark preview/depth than North Star, dashboard feel on Forecast/Classes/Focus/Notes.
- Required fixes applied afterward: tab-specific headers, reduced repeated behavior headline, compact daily surfaces, stronger Life/Widgets output preview.

## Student UX Reviewer

- Contact sheet: v2
- Overall: 7.2/10
- Category scores: 3-second understanding 7, next action 7.5, emotionally helpful 7
- Main issues: app felt system-centered, small/truncated labels, Import/Review needed one dominant action, repeated chrome competed with urgent work.
- Required fixes applied afterward: screen H1s now describe the student action, Life OS moved to supporting chrome, daily tabs expose one primary CTA.

## Personalization Reviewer

- Contact sheet: v2
- Overall: 5/10
- Category scores: visible adaptation 5, unique per student 4, Life Studio matters 5
- Main issues: personalization read as labels, tabs were too uniform, downstream changes were not visible enough, Paywall did not feel transformational.
- Required fixes applied afterward: adaptive badge/copy, behavior-specific card ordering/copy/colors, Plus preview copy tied to the user OS, Life tab output preview.

## Frontend Craft Reviewer

- Contact sheet: v2
- Overall: 6/10
- Category scores: native feel 5, no web-app slop 6, consistency 7, spacing/type 6
- Main issues: vertical clipping risk, repeated web-like card/pill grammar, compressed uppercase labels, bottom/header chrome dominance.
- Required fixes applied afterward: global web-like mode toggle removed from mobile header, daily shell softened, metric tiles compressed, final captures checked.

## Competitor Reviewer

- Contact sheet: v2
- Overall: 7.1/10
- Competitor comparison: Structured 7, MyStudyLife 8, Todoist 7, Google Calendar 5, Notion Calendar 5, Motion/Reclaim 6
- Main issues: missing full calendar/timeline credibility, repeated top module, AI import payoff not shown deeply enough.
- Required fixes applied afterward: retained existing planner/import contracts, surfaced Forecast risk and Review blockers above fold. Full drag timeline remains future work.

## Monetization Reviewer

- Contact sheet: v2
- Overall: 5.8/10
- Category scores: Plus worth paying 5.5, Life Studio subscription-worthy 5, paywall after value 7
- Main issues: Life Studio felt like setup, paywall abstract, weak premium visual payoff.
- Required fixes applied afterward: added Before Plus / With Plus value bridge and stronger user OS preview content.

## Widget/Watch Reviewer

- Category scores: glanceability 7, Apple Sports feel 6, watch/widget ecosystem potential 5.5
