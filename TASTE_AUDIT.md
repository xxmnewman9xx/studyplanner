# TASTE_AUDIT.md

Date: 2026-05-31

## Locked Reference

The uploaded Life Studio / Student Life OS image is the visual North Star:

- white-first canvas
- black type
- huge simple headline hierarchy
- colorful meaning cards
- central dark Life OS phone preview
- Apple Watch/widget previews
- visible adaptation from identity, layout, behavior, Widget DNA, and Watch DNA
- no poster boards inside the actual app
- no pasted images

Existing GPT Image references are also available under `marketing_exports/app_preview_slides_gpt_image_2/`, but many of those older plates are too purple/marketing-heavy compared with the new North Star.

## Blunt Taste Failures

- The current app is too gray and slate-heavy in important surfaces.
- Too many cards look like SaaS metric widgets.
- Text blocks are too explanatory. The North Star is direct and confident.
- The app still uses "dashboard" composition: hero, stats, cards, sections. The North Star uses a designed OS canvas.
- Purple CTAs dominate too many screens. The reference uses purple as one behavior color, not the product color.
- The bottom tab bar is close, but the screen body above it does not yet feel Apple Sports/Fitness/Watch Gallery.
- Some cards use decorative soft blobs/orbs, which reads less premium and conflicts with the requested visual discipline.
- Life Studio choices are visually interesting during onboarding, but the rest of the app does not look reconfigured by those choices.
- The existing UI is polished enough to pass a basic app review, but not distinctive enough to be remembered.

## Taste Standard For This Rebuild

- One dominant idea per screen.
- 3-second comprehension.
- Massive whitespace before density.
- Color only when it encodes meaning.
- Feed cards should feel alive and personalized, not randomly colorful.
- Action buttons should be confident and native, with icon + label where needed.
- Widget/watch previews should look like the ecosystem is a core paid feature.
- Empty states must feel like the OS is waiting for real school material, not like a blank admin panel.
- The app should look better in a simulator screenshot than in a code preview.

## What Must Disappear

- generic metric dashboards
- gray hero slabs
- card grids that exist only to fill space
- overexplained onboarding copy
- decorative gradients or bokeh/orb backgrounds
- fake AI chat affordances
- mascot/avatar energy
- web-style bordered panels
- a single purple product identity

## Visual Pass/Fail

Pass:

- A student can tell in 3 seconds what the OS wants them to do next.
- Life Studio behavior is visible in the feed, forecast, widgets, and watch preview.
- Screens look native and screenshot-worthy.
- The app feels like a personal operating layer for school and life.

Fail:

- It looks like a planner.
- It looks like a web dashboard.
- Life Studio only changes accent colors.
- Paywall appears before the user sees concrete value in the OS.
