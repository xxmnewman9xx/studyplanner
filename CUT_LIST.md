# Cut List

## Decision Frame

The current app should be judged against one spine:

**Guided onboarding -> profile builder -> scan/manual input -> hard paywall -> personalized dashboard.**

Anything that distracts from this spine should be cut, hidden, renamed, or moved behind Plus.

## Hard Cuts

### Complex Widget Studio

**Cut:** Editor-style widget configuration, multi-pack management, style fiddling, and "studio" framing.

**Replace with:** Recommended Widgets.

**Reason:** Students do not want another editor. They want the app to tell them which widget helps their school week.

### Theme Store

**Cut:** Theme browsing, decorative palettes, seasonal looks, visual marketplaces, broad appearance galleries.

**Replace with:** Class colors plus dashboard style.

**Reason:** Customization should improve recognition and ownership, not become a side product.

### Watch Visibility Unless Real

**Cut:** Watch tab, Watch previews, Watch paywall claims, Watch onboarding mentions, Watch widget packs, Watch screenshots if not backed by a real maintained Watch experience.

**Replace with:** Nothing until proven.

**Reason:** Unproven Watch claims weaken trust and increase App Store risk.

### Free Dashboard Access

**Cut:** Any route that lets users browse Home, Plan, Classes, Focus, Notes, Widgets, or Review before Plus.

**Replace with:** Locked paywall state after onboarding/input choice.

**Reason:** The dashboard is the paid product.

### Feature Tour Onboarding

**Cut:** Slides for Forecast, Classes, Focus, Widgets, Watch, Notes, themes, or generic planner features.

**Replace with:** Questions that build the student's profile.

**Reason:** Onboarding should personalize, not educate.

### Notes As A Main Tab

**Cut:** Notes as primary navigation.

**Replace with:** Contextual notes attached to assignments, classes, and focus sessions.

**Reason:** Notes do not sell the core promise and can make the app feel like a generic productivity suite.

### Focus As A Main Tab

**Cut:** Standalone Focus destination in primary navigation.

**Replace with:** Focus suggestions launched from Home, Plan, or Classes.

**Reason:** Focus is a response to a real deadline, not a separate habit app.

### Grades As Launch Spine

**Cut:** Grade prediction/grade manager as a first-session or primary tab promise.

**Replace with:** Semester Pulse as planning health, not grade prediction.

**Reason:** Grade claims are high-risk and not needed to sell the dashboard.

## Hide Until After Value

### Review Inbox

Hide as a destination. Surface only when scan/manual data has uncertain items.

### Recommended Widgets

Hide until the paid dashboard has enough data to recommend a widget.

### Customization Controls

Hide until Plus and after the dashboard exists.

### Calendar Sync And Reminders

Hide until dashboard value is clear. These are utility deepeners, not first-session selling points.

### Focus History

Hide until the user has completed sessions.

### Notes History

Hide until notes exist and can be linked to real work.

### Detailed Forecast

Show a simple risk signal on Home first. Put deeper pressure details in Plan.

## Rename / Reframe

| Current Concept | New Concept | Reason |
| --- | --- | --- |
| Today | Home | Home is the paid dashboard |
| Calendar | Plan | Forecast and workload are stronger than calendar browsing |
| Widget Studio | Recommended Widgets | Recommendation beats configuration |
| Themes | Dashboard style | Avoid theme-store sprawl |
| Watch | Hidden | Only visible when real |
| Review Inbox | Needs review alert | Trust checkpoint, not a destination |
| Focus timer | Focus suggestion | Tied to dashboard action |
| Notes | Class/assignment notes | Context, not a writing app |

## Navigation Cuts

Primary tabs should be:

1. Home
2. Scan
3. Plan
4. Classes
5. More

Remove or hide from primary nav:

- Today as separate from Home
- Notes
- Focus
- Widgets
- Watch
- Grades
- Review Inbox
- Customization
- Subscribe as a tab after purchase

## Copy Cuts

Cut language that says or implies:

- "Watch" unless real.
- "Live widgets" unless proven.
- "AI predicts grades."
- "Theme store."
- "Build your own widget."
- "Everything you need for school" as a generic claim.
- "Calendar" as the main product promise.

Use language that says:

- "Your school dashboard is ready."
- "Turn your syllabus into a personalized dashboard."
- "Next important thing."
- "Upcoming risk."
- "Recommended widget."
- "Class colors generated automatically."

## Product Surface Cuts By Timing

### Before Paywall

Allowed:

- Promise
- Profile questions
- Scan/manual input choice
- Source capture or minimum manual setup
- Auto-personalization summary
- Paywall

Cut:

- Dashboard
- Plan
- Classes
- Notes
- Focus
- Widgets
- Customization
- Watch
- Settings depth

### Immediately After Paywall

Allowed:

- Home
- Scan
- Plan
- Classes
- More
- Simple Recommended Widgets
- Simple customization in More

Still hidden:

- Watch unless real
- Theme store
- Widget editor
- Complex grade prediction
- Deep notes workflows

## Non-Negotiables

- No dashboard before paywall.
- No widget editor.
- No theme store.
- No Watch unless real.
- No feature-tour onboarding.
- No unsupported claims.
- No new tabs.
